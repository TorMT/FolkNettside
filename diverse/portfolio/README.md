# Public Portfolio

Denne mappen er den offentlige portefoljen for Tor T\u00f8nnessen.

- `index.html` er den offentlige portfolio-siden.
- `portfolio-data.json` er strukturert public data for profil, erfaring, prosjekter og preview-lenker.
- `preview/tool-preview.html` er en focused preview-wrapper for tool-only visning.
- `preview/` er markert med `.noindex` for å unngå automatisk promotering i genererte fillister.

Viktig:

- Denne mappen er separat fra `diverse/portfolio-template/`, som fortsatt skal holdes generisk.
- Preview-lenkene er presentasjonsmodus, ikke ekte tilgangskontroll.
- Ikke legg local/private JSON her uten \u00e5 utvide `.siteignore` og eventuelle lokale git-ignore-regler.

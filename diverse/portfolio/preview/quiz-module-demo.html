Quiz and Leaderboard Module

Demo of the reusable quiz module used on course-style pages, with JSON-defined questions, study mode, wrong-question mode and optional leaderboard support.

Back to portfolio Open JSON template
This is a focused preview of the quiz module itself rather than a full course page. Shared leaderboard support exists in the codebase, but this preview keeps the backend optional and does not pretend to be a full LMS or exam system.

Can

  • Render quizzes from JSON datasets
  • Support study mode, wrong-question mode and chapter filters
  • Reuse the same engine across multiple course-like pages

Limits

  • Depends on curated question sets and page wiring
  • Leaderboard features need the PHP/SQLite backend to be enabled
  • It is not intended as a full learning management system

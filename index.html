Velkommen til mi side

Dette er startsiden. Her finner du informasjon, navigasjon og innganger til fag og ressurser.

Nytt nytt og funksjoner

  • Videoviseren grupperer nå forelesninger bedre, med søk, temaer, gruppebeskrivelser og markering som sett.
  • Fluid og Fysikalsk kjemi bruker nå oppgraderte forelesningslister med bedre deling av deler og tema.
  • 3MF-viseren har fått komponentliste, highlighting, rapportskuff og bedre hydrostatikk-flyt.
  • Fusion- og F3Z-filer får egen lokal åpner med metadata, container-visning og STL-fallback ved behov.
  • SiteUpdater har backup, dry-run og rollback, og brukes nå tryggere på `diverse` og `semestre`.
  • Brygging er nå en samlet hub med RAPT-hydrometere, bryggelogger, oppskrifter, beer overview og gjæringsanalyse.
  • Oppskrifter kan skaleres automatisk, matches mot malt og humle du har på lager, og kobles til flere bryggelogger.
  • Eksterne øl- og bryggeridata vises nå som innebygde kort på siden i stedet for bare eksterne lenker.

Gammelt nytt og funksjoner

  • Passordbeskyttede mapper.
  • PDF-viewer med fallback.
  • Velkomstbilder per fagmappe.
  • HTML-, kode- og notebook-visere for egne filer.
  • Hydrometer-integrasjon med lokal cache og filtrerte grafer.
  • Kodekjøreren kan kjøre nestede Python-programmer med egne importerte filer.
  • Layout smoothness.
  • Mobilvennlighet på hovedsider og sidepanel.
  • Webstatistikk og analytics på forsiden.
  • Quiz til fag med historikk, temaer og grunnleggende topplisteflyt.
  • Du kan nå lese kode i farger.
  • Eksperimentell funksjon: kjør koden direkte på siden.

Pågående arbeid

  • Videre opprydding i tegnkoding og navn i enkelte `index.json`-filer.
  • Fusion/F3Z-åpner som viser selve CAD-fila enda mer direkte uten eksterne toppmenyer.
  • Hydrostatikk-rapport med bedre beregninger og penere eksport/PDF-flyt.
  • Quiz-modul med mer komplett leaderboard, studymodus og mobilforbedringer.
  • Autodesk APS-integrasjon for å hente Njord-modeller direkte fra hub/prosjekt.
  • Videre utvidelse av Brygging med flere råvarekataloger, Drive-synk og enda bedre sammenligningsmodeller.
